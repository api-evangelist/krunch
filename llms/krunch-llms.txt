# Krunch

> Krunch is an on-demand product studio delivering product management, engineering,
> and marketing as a service, using AI and code. Krunch is a services agency, not an
> API provider: it has no public API, developer portal, documentation, SDKs, or
> machine-readable API artifacts.

Generated by the API Evangelist enrichment pipeline. Last verified 2026-08-13 against
apis.yml and live probes of www.krunchdata.io. Krunch does not publish its own
/llms.txt (probed 2026-07-19 and again 2026-08-13, HTTP 404 both times).

## What Krunch does

- On-demand product management, engineering, and marketing services
- Delivery is AI- and code-assisted rather than staff-augmentation-only
- Accepted into the 500 Startup Accelerator program (Silicon Valley); backed by 500 Global
- Publicly named prior engagements: Alibaba, Google, Camunda, New Relic, Polkadot, Bowtie
- Headquartered in Hong Kong with operations in San Francisco (per third-party company
  registries; not stated on the Krunch site itself)

## For agents

- There is no Krunch API to call. No base URL, no authentication scheme, no OpenAPI,
  AsyncAPI, GraphQL SDL, or MCP server exists as of 2026-08-13.
- Contract discovery was run in full on 2026-08-13 and missed on every path:
  /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json, /api-docs, /redoc,
  /docs, /api, /developers, /graphql (GET and POST introspection), /mcp and /sse all
  return 404. There is no docs or console host to try them against.
- No A2A agent card is served: /.well-known/agent-card.json and the legacy
  /.well-known/agent.json both 404.
- No first-party Krunch package exists on any registry checked (npm, PyPI, GitHub).
  Note the name collisions: the npm package `krunch` is an unrelated JavaScript
  build/watch tool by larron, and the GitHub repo `JustSteveKing/krunchdata` belongs to
  an unaffiliated developer. Neither is published by this company. `krunchdata` on npm,
  `@krunch/sdk` on npm and `krunch` on PyPI all 404, and no `krunch` or `krunchdata`
  GitHub organization exists.
- No developer subdomain resolves: docs., api., developer., app., blog., dashboard.,
  help., support., beta. and staging.krunchdata.io are all NXDOMAIN.
- The /.well-known/ surface is empty (see well-known/krunch-well-known.yml): no
  security.txt, no OpenID Connect or OAuth authorization-server metadata, no
  oauth-protected-resource, no api-catalog, no ai-plugin.json, no agent card.
- robots.txt (HTTP 200) is 24 lines of Cloudflare Content Signals Policy comment
  boilerplate with no directives and no signal values set - it neither grants nor
  restricts anything, and carries no sitemap or discovery hint. /sitemap.xml is 404.
- Domain security posture is probed in security/krunch-domain-security.yml: HTTPS with
  TLS 1.3 and HSTS (max-age 63072000) on www.krunchdata.io, but no DNSSEC, no CAA
  records, and - despite Google Workspace MX records on the domain - no SPF and no
  DMARC. That combination means Krunch's own domain can be spoofed in email.
- No security disclosure program and no trust center were found (probed 2026-08-13).
- No pricing is published: plan_count is 0, the model is contact-sales, and the entire
  commercial surface is the Calendly link (see plans/krunch-plans-pricing.yml).
- Engagement with Krunch is a sales conversation via the Calendly link, not a
  self-service signup.

## Historical note

Krunch previously operated as "Krunch Data - The Developer Community Cockpit", a
developer-relations analytics product measuring content attribution to GitHub
engagement. Third-party directory listings from that era describe "a flexible set of
application programming interfaces (APIs) for developers to integrate and extract data";
no such API is published today, and no archived Krunch API reference or specification
was located. Treat those directory claims as marketing copy about a retired product,
not as evidence of a callable contract.
